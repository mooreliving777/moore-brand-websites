## Included

Each site has a distinct palette and composition, relevant existing imagery, service/exploration links, published article cards where available, and original inquiry/newsletter/booking links. No package dependencies, tracking scripts or credential forms.

## Scope

These are companion landing websites, not full WordPress migrations. WordPress pages and settings were not changed. Articles and service forms continue on the source websites. No payment or subscriber records are copied.

Blog cards and sources are a static snapshot from October 25, 2026. Subsequent updates continue on WordPress. Brand imagery remains hosted at the existing WordPress URLs and depends on those sources remaining available.

The Harsh Truth images represent concepts and developing merchandise, not confirmed inventory. Bridge to Better program availability must be confirmed directly; no emergency housing or immediate assistance is promised. B3 bookings and current pricing continue on the original booking service.

Rich Nerdz Nation is represented as a legacy companion because its Jetpack connection is disconnected and its original public site could not be verified. The Rich Rapper WordPress site is marked coming soon. Neither companion republishes unpublished material. Their editorial studio imagery comes from the network’s published Fireworks TV library.

Each brand page has a canonical reference to its original WordPress address. The directory has its own canonical URL.

## Build and preview

Run `python scripts/build.py` to rebuild from reviewed copy and the sanitized public source snapshot. Run `python -m http.server 8080` to preview at http://localhost:8080. GitHub Pages deploys from `main`, `/ (root)`.

## Source data

`data/source-snapshot.json` includes selected public page/post metadata and sanitized image/video pointers. It excludes subscribers, admin information, unpublished content, raw page markup, API keys and authenticated access metadata. `data/site-map.json` maps companion routes to source sites.
