## Acceptance before merging code to GitHub Pages

- [ ] Compare each current official source page with its companion; correct only verified stale information
- [ ] Confirm no broken outbound CTA/booking/contact links or redirects
- [ ] Check all hero/product assets on desktop and mobile; no black screens, phony generated portraits, or stretched images
- [ ] Check headings, contrast, responsive overflow, keyboard navigation, alt text and effective page hierarchy
- [ ] Keep each brand identity and voice distinct; no repetitive boilerplate layouts
- [ ] Validate SEO canonical URLs and which platform should index for each brand; avoid competing copies
- [ ] Run build locally, inspect preview, and document exact pages changed
- [ ] Obtain approval for exact visual/content changes before merge; no auto-deployment from this draft
