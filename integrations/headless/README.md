# Moore Network Portable Motion Kit — Review Branch

Scope: reusable CSS/JavaScript for existing static/headless Wix-hosted sites and future Hostinger sites. Not a WordPress plugin, not a new site, and not a deployed update.

Files: motion.css and motion.mjs. No dependencies, tracking, API charges, cookies, forms, checkout or account access.

To prepare a source-code adaptation, copy both files into the site's assets folder. Link CSS in head and the JavaScript module before the closing body tag. Add a data-moore-motion brand key to the page wrapper and optional data-mm-progress attribute. Apply data-mm=hero on introductory copy, data-mm=hero-media on featured media, data-mm=reveal on lower sections, data-mm=interactive on visual CTAs, and data-mm=hover-media on a photo wrapper. Do NOT target checkout, forms, menus or modals.

Brand keys: city-web, computer, clothing, harsh-truth, moorvio, fireworks, amanda, b3, legacy, foundation, leonard, developer, richnerdz.

IMPORTANT RELEASE GATE: Wix Headless static upload to an existing site updates live hosting. Reuse only the verified original site code, snapshot assets and test carefully. No Wix upload is approved or performed as part of this package.

WordPress.com read-only inventory: City Web uses Fewer; The Harsh Truth Clothing uses Ellusive; Fireworks TV uses Streamer; Leonard Moore uses Mann. On November 13, 2026 a custom style block was stripped from City Web's unpublished home redesign draft by the host. Its inserted test block was removed and the draft's original content hash restored. Do not assume these WordPress.com simple sites accept custom CSS/JS. Their GitHub companion sites are motion-ready drafts.

Review checks before live deployment: no JS fallback, reduced motion (including mid-session changes), narrow/mobile and desktop widths, keyboard and touch, long-page scroll, loading and animation performance, original artwork, links, genuine garment photography and review gates. Publish only after separate release authorization.
